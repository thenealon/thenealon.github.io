# apps/

Drop a self-contained `.html` file in here and it shows up in the **Web apps**
gallery on the extras page automatically — its name comes from the file's
`<title>`, and its thumbnail is generated from that name. Nothing else to do.

- One file per app. It can pull in its own CSS/JS, or be a single file.
- The `<title>` is the label shown under the card.
- Delete `example.html` once you have your own.
